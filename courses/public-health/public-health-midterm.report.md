## Conflicts — the circulating claims are wrong on these 6

- **PH-M-016** — "How does a cohort study differ from a case-control study?"
  Claimed "cohort studies require many years, case-control doesn't" — source
  frames that as a conditional practical issue, not the definitional
  distinction; the source-backed answer is the structural one: cohort groups by
  exposure status at enrollment, case-control doesn't.
- **PH-M-019** — Obesity/physical-activity OR question. Claimed OR 0.3 (CI
  0.1–1.4) as the "significant negative association" — but that CI spans 1, so
  it isn't statistically significant. OR 0.7 (CI 0.2–0.8) is the only option
  that's both negative *and* significant.
- **PH-M-041** — "Most accurate definition of social determinants of health."
  Claimed the option naming genetics as part of SDOH — but genetics is a
  separate determinant category from *social* determinants in this course's own
  framework. The CDC/WHO-style "born, live, learn, work, play, worship, and
  age" option is the real SDOH definition.
- **PH-M-139** — "Physicians are the largest group employed in public health"
  (claimed True) — Palestine's own workforce table in this same course's
  source shows nurses (14,593) outnumber physicians (11,313).
- **PH-M-158** — UHC financing question (claimed False) — the universal-vs-
  targeted-programs pooling logic this course teaches is precisely the standard
  argument *for* the claim being True.
- **PH-M-170** — Attributes an industrial-production-focused prevention
  description to the Multi-Causal Theory (claimed True) — that description is
  actually the Environmental Theory's definition.

Two more of this shape resolved the *other* way — the claim held up once
checked, they just looked risky going in: **PH-M-137** and **PH-M-168** both
attribute a description from one named theory/concept to a different one, and
in both cases the exam's own claimed answer (False) correctly caught the
mismatch.
