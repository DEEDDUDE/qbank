**Conflicts (5)** — the circulating claims are wrong on these; source wins in every case:

- **MICRO-Q-001** — claimed c (K. pneumoniae and S. pneumoniae, both "Gram-negative");
  the source's own classification table makes S. pneumoniae Gram-positive, so only
  K. pneumoniae fits the stem → a.
- **MICRO-Q-030** — claimed b (mold fungi and C. tetani reproduce by spore production);
  Ch. 2 frames bacterial endospores as dormancy/survival structures, never reproduction,
  while Ch. 15 explicitly calls fungal spores reproductive → c (mold fungi alone). Same
  distinction already caught at MICRO-M-003 in the midterm batch.
- **MICRO-Q-031** — claimed d (Coronavirus causes perinatal infection); the vertical
  transmission table names Hepatitis B virus for birth-canal/at-birth transmission, and
  none of the other three options appear in that table at all → b.
- **MICRO-Q-036** — claimed d (protective antigen forms pores) as the exception to
  B. anthracis's toxins; the source confirms b, c, *and* d are all accurate, so the
  "except" answer is a) None of them.
- **MICRO-Q-040** — claimed d (Amanita fungi produce aflatoxin); the source names
  Aspergillus flavus as the aflatoxin producer, Amanita poisoning is a separate,
  unrelated mycotoxicosis → c.
